# 彤彤消消樂

手機、平板與電腦瀏覽器皆可遊玩的原創三消遊戲。

## 開啟方式

- 直接開啟 `彤彤消消樂_免安裝手機平板版.html`：所有圖片與音樂都已包含在單一檔案內。
- 開啟 `彤彤消消樂.html`：需保留旁邊的 `assets` 資料夾。

## 操作

- 滑動糖果，或依序點選兩顆相鄰糖果進行交換。
- 三個相同角色連線即可消除。
- 四消會產生直線糖果，五消會產生彩虹糖果。
- 在步數用完前收集指定數量的目標角色。

## 功能

- 8×8 三消棋盤、連鎖掉落與無解重排。
- 特殊糖果、提示、分數、步數、關卡與本機最高分。
- GPT 繪製的六種角色糖果及糖果遊樂園背景。
- 背景音樂、音效、重新開始與關閉停音。
- Safari 進入背景、鎖定螢幕或關閉分頁時自動停止聲音。
